# Python Data Analysis Toolkit

## CSV Profiler

A lightweight Python utility for profiling CSV datasets before analysis.

### Checks

- File validation
- Row and column count
- Column names
- Data types
- Missing values
- Duplicate rows
- Unique values
- Numeric statistics

### Execution

The tool runs inside the project's Docker Jupyter environment.

  ↓
